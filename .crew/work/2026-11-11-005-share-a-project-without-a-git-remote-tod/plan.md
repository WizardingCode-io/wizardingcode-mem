Revision 3, for `spec.md` revision 6 (both review rounds' findings applied; the history is in `conclave.md`). Every task names its criterion, marks each file `Create` or `Modify`, and ends with a red run then a green run; every phase leaves `bun run check` green and typechecks on its own. The tests run with the pinned Bun (`./node_modules/.bin/bun test <files>`), never the global one; `bun run lint` checks no file inside a crew worktree, so the lint is run as `./node_modules/.bin/biome check src tests ui/src scripts` before the gate.
