  - propose-fix: The spec will state the loss that forces the eight-table carry: after a restore from an older copy, own items the server holds that the restored ledger does not know would read as teammates revisions at the snapshot (the own file overwritten by the server revision, or a false conflict), the old generation withdrawal needs the sent rows, a refusal not carried re-sends a refused hash, and a conflicts row keeps the server revision and hash the rollback test needs; the snapshot cannot rebuild the ledger because it tells an own item from a teammate one by that ledger.
