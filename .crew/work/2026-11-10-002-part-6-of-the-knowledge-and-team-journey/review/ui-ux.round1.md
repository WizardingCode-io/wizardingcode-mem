- F-1 · defect · src/ui/api.ts:106 · /projects receive (all 6 captures): AC-24 says the dock "offers Receive only" and the manifest says the receive state has "the radio list with 'Receive only' chosen", but every receive capture shows the dock's label "Nothing" and the "Nothing" radio checked under "Bound to 127.0.0.1:59812.", although the script set the level with `setLevel(..., "receive")` (probes/capture-part6.ts:317). The project list's `sharing` comes from `levelOf`, which returns the sending level, and `effectiveLevel` turns receive into local (src/sharing/levels.ts:151), so ProjectsView.vue:315 can never show Receive only. Because ProjectsView.vue:139 returns early when `level === p.sharing`, a project at Receive only also cannot be set back to Nothing from the dock (projects-receive@1280-dark.png, projects-receive@768-dark.png, projects-receive@360-dark.png, projects-receive@1280-light.png, projects-receive@768-light.png, projects-receive@360-light.png)
