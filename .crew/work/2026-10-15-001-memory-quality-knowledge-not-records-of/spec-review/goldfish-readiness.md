## Findings
- F-1 · Major · Task 3, Step 2, `describe("distill: the notes the session had been shown")` and Review Focus 3 · No test checks the time bound (`i.at <= ended_at`) on its own. Test 1 injects the memory made from the same turn after the turn ended. The new `m.source_turn_id <> ?` clause already excludes that memory, so the test passes without any time bound. Test 2 also covers only the same-turn exclusion. Test 3 covers only the null branch. Code that drops `AND (? IS NULL OR i.at <= ?)` and keeps only the same-turn exclusion passes all three tests and the AC-11 green. Review Focus 3 says this behaviour is tested, and it is not. Missing: a case where a memory from a different turn of the same session is injected after this turn's `ended_at`, and its sentences must still reach the judge.
- F-2 · Major · Spec line (line 11) against Task 6's opening paragraph · Line 11 says "the spec wins; the one known difference is stated in Task 6 (the version 1 builder)". Task 6 never states that difference: it cites "spec section 7" as support for keeping the whole version 1 builder. The spec (around line 305) says only that `wording: 1` gives the version 1 `worth`, `kind` and `importance`. A reader who follows "the spec wins" can cut the version 1 builder down to those three questions. That breaks the `durable_<i>`/`title` test of `tests/unit/questions.test.ts` and the proof's wording-1 token and verdict measure in Task 7. Missing: one sentence in Task 6 that says what the spec says and that the plan overrides it there.

It fails safe, but in that setup the proof cannot run, and the plan does not say how this case should behave.
