## Findings
- F-1 · Major · Why, finding 3 (line 20); Decisions, "A cheap filter…" (line 30); §1 "Rules for the list" (line 65) · All three say the filter admits "only patterns with 97–100% precision", but the table at lines 61–62 admits `protocol-tag` at 0.88 and `verdict` at 0.80, each justified by an argument rather than a measurement. `status-label` (4 hits) and `template-label` (2 hits) score 1.00 on samples too small to support a 97% claim. A reader would take the 97–100% bar as met for every pattern and would not know that two patterns entered on reasoning alone. The claim needs to name the exceptions or say that sentence-level precision has not yet been measured.
- F-2 · Major · Decisions, "…Reversible, same code as the live path, nothing deleted." (line 32); §5 Reversibility (line 186) · "Reversible" is stated without limits. `--undo` reverses only "the last run", but the command is resumable and bounded by `--limit`, so a cleanup can take several runs. The `duplicate` action "reinforces the target", and `--undo` does not undo that. Consolidation "as today" can change neighbouring memories, and `memory_reviews` does not record those changes. "Nothing deleted" is also loose, because `--undo` deletes the review rows. A reader would treat the cleanup as fully undoable and miss these side effects.
- F-3 · Major · §5 The dry run (line 192) against §7 (line 235) · Line 192 says `--dry-run` "writes nothing to `memories`", and §7 tests "the dry run writing nothing". Line 186 makes a `memory_reviews` row the marker that a memory is done. If an implementer reads line 192 literally and writes review rows during the dry run, the real run then skips every memory. The text should say whether the dry run writes nothing at all or only nothing to `memories`.
- F-4 · Major · §6 Metrics, first row (line 212) · The "Before" value of 9% is the share of the old sample labelled Knowledge, a label on the whole memory. The "Target" measures whether the title is the knowledge sentence. These are different measures, so 9% to ≥60% reads as a like-for-like gain when it is not. The Title-only row has the same problem: its 16% is 411/2,513 from the whole-store count at line 22, not from "sample of 2026-10-13" as the column header says.
- F-5 · Nit · §5 The dry run (line 192), "about $0.21 at the published price" · The source of the price is not named: which model, which price page, read on what date. 5 M tokens for $0.21 implies about $0.04 per million tokens, and a reader cannot check that. The same vagueness is at §4, line 153: "(about 40 turns, cents)".
- F-6 · Nit · Why, finding 2 (line 19), "TypeSafe approved nearly everything, nearly all at importance 4" · The section gives counts everywhere else, but this sentence gives none. Give the approval share and the share at importance 4.
- F-7 · Nit · Throughout: "TypeSafe", "`noul`" (lines 85, 92), "the mem", "the drain" / "drain lease" (lines 162, 196), "gate", "the brief", "hand-back", "W4" · These terms are never defined. "`noul`" in particular cannot be decoded from the document. The Heilmeier rubric's question 1 asks for the goal "with no jargon at all"; one gloss per term on first use would cover it.
- F-8 · Nit · Decisions, last item (line 34), "`memory_save` stays the agent's high-quality route" · "High-quality" is an unmeasured judgement. Say what makes it different, for example that it is saved by the agent explicitly and skips the judge, if that is the fact.
- F-9 · Nit · Why table (line 9) against §6 (lines 205, 212–216) · The table calls the label "Knowledge", but later sections use `keep` for the same label and never map one to the other. "Durability penalties" in §4 (line 149) keeps the old "durable" wording after §2 renames the concept to `knowledge`.
- F-10 · Nit · Why table (lines 11–14) · Rounding is inconsistent: 117/200 = 58.5% is shown as 58%, and 7/200 = 3.5% is shown as 4%. The shares add up to 100% only by accident, and line 214 then uses 62% (58.5 + 3.5).
- F-11 · Nit · §5 Reversibility (line 188), "so it costs no extra compatibility" · The phrase is unclear. It probably means "no released database needs a separate upgrade step"; the sentence should say that.
- F-12 · Nit · Why, finding 3 (line 20), and Decisions (line 30), "Cheap signals" / "A cheap filter" · "Cheap" is never defined. The meaning, no request to the model, should be said once.
- F-13 · Major · Whole document, against spec-feature.md "Alternatives" and "Risks and limits" · There is no alternatives section. The one alternative named, generative rewriting (lines 29, 246), is set aside by appeal to a founding rule and "a separate conversation", not for a stated cost or risk. Other alternatives, such as filtering alone or changing the thresholds alone, are not discussed. There is no risks section either. One example: the drain lease blocks live distillation for the whole run (line 162), and how long a run takes is unknown until the ADR records it (line 223). A reader cannot confirm that the alternatives and risks were faced, which is this rubric's pass condition.
