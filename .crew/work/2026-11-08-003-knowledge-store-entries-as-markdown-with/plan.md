# Plan: the knowledge store

Every task names its criterion and ends with a red or a green run. The test command for one file is `./node_modules/.bin/bun test <file>`; the full suite is `bun run test` at the gate. No implementation code here: shapes, cases and commands. Each phase leaves the tree buildable: `bun run typecheck` passes at the end of every phase, so no test file imports a module a later phase creates (the types and `openStore` are created first, in Phase A). Tests that need git create their data directory under `tmpdir()`, set `HOME` to a throwaway folder and pass their own `env` to the store, so no test touches the person's git configuration or depends on the shell's `PATH`. Tests that write thousands of files or rows set a 30 s timeout on themselves.
