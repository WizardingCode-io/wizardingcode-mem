- `goldfish-codebase` codebase-2.9-6 · Signatures, `src/store/compact.ts` (dry run) and task 18 · The dry run counts "the rows that match that condition, plus the rows whose session the run would remove". A `knowledge_shown` row whose repository is gone and whose session the run would remove matches both, so a literal sum counts it twice. The real run deletes it once. That breaks task 18's claim that the dry run "reports the same number". The plan should say the two conditions are OR'd in one count.
  - propose-fix: The dry run is one count over the two conditions joined by OR (the row's repository is gone, or its session is gone or would be removed by this run), so a row that matches both is counted once and the dry run reports the number the real run deletes.
