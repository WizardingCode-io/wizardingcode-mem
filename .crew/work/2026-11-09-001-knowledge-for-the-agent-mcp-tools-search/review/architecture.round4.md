## Findings
- F-1 · advisory · src/modules/knowledge/tools.ts:113 · Carried from round 3 F-3, unchanged. `rootAreas` still reads a root's taxonomy file by hand (`kindAt`, `readRegularFile`, `parseTaxonomy`), copying part 1's `taxonomyFor` (repo.ts:712) except for its fallback. The CLAUDE.md text this diff writes says "`doctor` is the one reader that does not go through `openRepo`" and that doctor reads by hand under `refuseLinkedRoots`, `refuseForeign` and `checkRepoConfig`. `rootAreas` is a second hand reader with none of those guards. It runs no git, so this does not cross the git boundary. Still, a guard added to `taxonomyFor` later will not reach the area enum. Fix: wrap `taxonomyFor` (catch a refusal or null and return `DEFAULT_AREAS`) using a store that has only a dataDir. Alternatively, name the second reader in CLAUDE.md.
- F-2 · advisory · src/retrieve/render.ts:99 · Carried from round 3 F-4. `KNOWLEDGE_LINE` writes knowledge's two intros and its count line as regex literals. It does not build them from `INTRO`, `PROMPT_INTRO` and `pinnedCountLine` in contribute.ts. If either intro changes, echoes stop being stripped and get distilled, with no error. Fix: build the pattern from the exported constants, escaped.
- F-3 · advisory · docs/adr/0019-one-engine.md:20 · Carried from round 3 F-5. The contract paragraph of ADR 0019 still says `ToolCall` is `projectDir` alone and does not list `globalInstructions`. The reversal note (line 141 of the diff) names F5′ but not the two contract additions in module.ts. ADR 0024 part 2 (line 228) records them. Fix: add one clause to the reversal note pointing to ADR 0024's list of the additions.
- F-4 · advisory · src/judge/types.ts:57 · Carried from round 2 F-3. The new `ConsolidateTexts` types `title` and `body` as plain `string`. `consolidateState` and `consolidateQuestions`, which build the TypeSafe request, now take it, so the `Redacted` type no longer guards the place where text leaves the machine. Both entry points (`ConsolidateInput`, `RelateInput`) still require `Redacted`, so nothing leaks today. Fix: type the draft's and the neighbours' `body` (and `title` where the entry point brands it) as `Redacted`.
- F-5 · advisory · src/modules/knowledge/index-store.ts:806 · The step that forgets a gone repository (`dropRepoRows` plus the `knowledge_repos` delete, in one `withWrite`) is now written twice: in `refreshOne` and in `rebuildAll` (index-store.ts:757-761). Both sit behind the same refusals, but the base wants "only a name with nothing at it is gone" to live in one rule, and the Design says the drain forgets "by `rebuildAll`'s own rule". Fix: move it into one helper, e.g. `forgetIfGone(store, row)`, that both call.
