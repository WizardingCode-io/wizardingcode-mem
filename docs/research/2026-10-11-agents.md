# A6: next agents for wizardingcode-mem (research as of 2026-10-11)

Legend: [OD] official docs fetched; [SS] secondary source (blog, third-party integration docs, search snippet); [?] unknown / not found.

## Big landscape changes (affect our current support)
- Gemini CLI retired for most users on 2026-06-18; replaced by closed-source Go "Antigravity CLI" (`agy`). [SS: dealroom, inventivehq, mcp.directory]. Our existing Gemini adapter covers a dying target; Antigravity CLI is the successor and has hooks + context injection.
- Windsurf renamed "Devin Desktop" (June 2026); docs moved to docs.devin.ai. [OD redirect + SS]
- Roo Code (24k stars) archived itself. [SS]. Do not invest.
- Kilo Code CLI is an OpenCode fork and uses OpenCode's plugin system [SS]. Our OpenCode package may work almost as-is.
- Block handed Goose to the Linux Foundation. [SS]

## Key facts per tier-1 candidate (what the adapter would look like)

1. **Qwen Code**: Claude-Code-shaped hooks (SessionStart / UserPromptSubmit / Stop / SessionEnd), additionalContext, JSONL transcripts under `~/.qwen/projects/*/chats`, stdio MCP in settings.json. Almost a copy of our claude-code adapter. Caveat: transcript record schema not verified from docs; hook payload may carry transcript_path (verify in a real session).
2. **Factory Droid**: Claude-Code-compatible hooks with additionalContext on SessionStart/UserPromptSubmit. Likely cheapest adapter. Closed source, narrower reach (enterprise). Transcript format unverified.
3. **Antigravity CLI**: only Gemini successor; hooks.json at `~/.gemini/config/`; PreInvocation `injectSteps` is a real injection channel; Stop gives end-of-turn; transcriptPath supplied. Gaps: no SessionStart/UserPromptSubmit/SessionEnd (use PreInvocation with invocationNum==1 as session start; the prompt must be read from transcriptPath). Also shares `~/.gemini/` so our Gemini installer paths partly overlap. High reach because Google forced migration.
4. **Copilot CLI**: sessionStart additionalContext (static brief at start) + MCP + `events.jsonl` + native plugin mechanism. The weakness: no per-prompt injection (userPromptSubmitted output dropped). Hooks do get prompt text for capture. Still the best reach in the list; plugin install via `copilot plugin install`.
5. **Copilot in VS Code**: same hook JSON files (`.github/hooks`), SessionStart additionalContext; Copilot CLI hook file may serve both with PascalCase names. Payload differs per harness; verify.
6. **Augment Auggie CLI**: SessionStart stdout injection, SessionEnd, Stop; no UserPromptSubmit. Smaller reach.
7. **Kiro**: CLI v3 userPromptSubmit/SessionStart stdout into context + MCP + steering files. v3 hooks migration is fresh (format churn). Reach: AWS push, growing.
8. **Amp**: strong plugin API (agent.start returns an appended message; thread.messages for history) but TypeScript-in-Bun, experimental, "breaking changes expected". Different adapter style (like our OpenCode package).
9. **Cline**: SDK plugin `before_agent_start` can inject; plugin install via npm/git. Plugin API is new (SDK rewrite); I could not confirm transcript path or hook payloads from docs.

## Ranking

**Tier 1 (hooks + context injection + MCP)**
- Qwen Code, Factory Droid, Copilot CLI (session-start injection only), Copilot in VS Code (same), Antigravity CLI (PreInvocation injection), Augment Auggie (SessionStart only), Kiro CLI, Amp (plugin), Cline (SDK plugin), Pi (extension), Kilo (OpenCode plugin API).
  - Strongest full-experience (start + per-prompt + end): Qwen Code, Factory Droid, Kiro CLI, Amp, Cline plugin.
  - Partial (injection at start/invocation only): Copilot CLI/VS Code, Antigravity, Augment.

**Tier 2 (MCP + rules/instructions file we can write)**
- Windsurf/Devin Desktop (hooks exist but observe-only; rules `.windsurf/rules/`; plus `post_cascade_response_with_transcript` for capture), Zed (rules + context_servers), JetBrains Junie (AGENTS.md, mcp.json), Continue (rules + mcpServers), Warp (AGENTS.md + MCP), Goose (`.goosehints` + MCP), Aider (CONVENTIONS.md; MCP support unconfirmed), Roo (archived; skip).

**Tier 3 (MCP only / minimal)**
- Crush (only PreToolUse hook, no injection; MCP yes). Note Windsurf could be tier 1.5 for capture (transcript + hook) but has no injection.

## Recommendation: next 3-5 by reach x effort

1. **Antigravity CLI** - Reach: Google forced Gemini CLI's 100k+ users here; we already ship a Gemini adapter that is now on a retired product. Effort: medium (new events, hooks.json, injectSteps output, GEMINI.md/rules fallback). Highest priority also because it is maintenance of existing coverage.
2. **GitHub Copilot (CLI + VS Code agent mode, one adapter)** - Reach: largest installed base. Effort: medium; one `.github/hooks/*.json` / `~/.copilot/hooks` file serves both; plugin.json for CLI. Limitation: no per-prompt injection, so inject a brief at sessionStart and rely on MCP; capture prompts via userPromptSubmitted.
3. **Qwen Code** - Reach: ~25k stars, big in Asia; Effort: low (Claude-Code-shaped hooks and JSONL). Cheapest full-experience adapter.
4. **Factory Droid** - Reach: modest, enterprise-paying; Effort: low (Claude-compatible hooks.json). Quick win.
5. **Kilo Code CLI** (or Kiro) - Kilo: probably covered by reusing the OpenCode package (verify plugin dir `~/.config/kilo/plugins`); Kiro CLI v3 if AWS reach matters. Defer Amp/Cline until their plugin APIs stabilise; skip Roo (archived).

Also: Windsurf/Devin Desktop worth a rules+MCP tier-2 install (cheap) since the user base is large.
